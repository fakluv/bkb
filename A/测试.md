## 三、界面不显示或不刷新数据（清除缓冲）

#### 1.bd300

- ps -ef|grep mem ：**过滤缓存进程**
- systemctl status memcached-repcached ：**查看缓存状态**
- systemctl restart memcached-repcached ：**重启缓存**

#### 2.bd400

- ps -ef|grep redis  ：**过滤缓存进程**
- systemctl status redis ：**查看redis缓存状态**
- redis-cli -h 127.0.0.1 -p 6379  ：**登录**
- auth tct@redis ：**验证**
- keys * ：**查看所有key值**
- del key ：**删除指定索引的值**
- flushall ：**清空整个 Redis 服务器的数据**
- flushdb ：**清空当前库中的所有 key**
- systemctl restart redis ：**重启缓存**

## 四、环境起不来排查思路

### 1.bd300

- **检查配置**
  - 1、检查**<u>dic_mss_system_config</u>**表里面的采集和应用IP是否配对
  - 2、检查**<u>/var/local/project/mss-app-bdms300</u>**下面的application.yml的IP是否配对
  - 3、检查**<u>/var/local/project/mss/WEB-INF/classes/spring</u>**下面的**<u>spring-data/spring-mq/spring-memcached</u>**的IP是否配对
  - 4、检查**<u>/usr/local/nginx/conf</u>**下反向代理的IP和端口是否配对
  - 5、检查tomcat是否起来 <u>**ps -ef|grep tomcat**</u>
  - 6、检查中间件缓存、mq、mysql、nginx是否起来    systemctl status memcached-repcached     **<u>systemctl status mq</u>**  **systemctl status mysql**

- **查看日志**
  - 查看**采集日志**，cd到<u>**/var/local/project/mss-app-bdms300**</u>下面，执行命令 **<u>sh mss-app-test.sh</u>**，启动test脚本查看采集日志是否有报错，少表少字段还是哪里dic_mss_system_config没配对
  - 查看**应用日志**，cd 到**<u>/var/local/apache-tomcat-8.0.33/logs</u>**下面，执行命令**<u>tail -f catalina.out</u>**，查看应用日志否有报错，少表少字段还是哪里dic_mss_system_config没配对，或者是中间件挂了，数据库挂了没连上等问题
